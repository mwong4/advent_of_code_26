# advent_of_code_26

Advent of code for 2026!

## Setup

To participate, add your name to the `PARTICIPANT_NAMES` array in `populate.py` before running the script.

```CLI
$ py populate.py
WARNING, THIS WILL CLEAR ALL PREVIOUSLY WRITTEN CODE. DO YOU WANT TO CONTINUE?
Type 'y' to confirm: y
```

**WARNING** This will clear all previous work, only run this at the start
